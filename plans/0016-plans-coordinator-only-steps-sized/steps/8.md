## Approach

- **The sentence** (D7, verbatim) goes into every prompt that starts a plan-running session; tests assert it where the
  prompt lives in a script (fix-loc's `fill_prompt`, implement.py's FALLBACK and any loaded template).
- **sanity-watch**: `scan.py` reads each session's `background_tasks`: a shell or monitor counts as live; a subagent
  counts as live unless its transcript (`<projects>/*/<session>/subagents/agent-<id>.jsonl`) has been quiet 20 min.
  An idle session with a live task is skipped (D14); one with only dead subagents is the new class F14 "subagent
  dead under an idle parent" (`judge`), whatever its plan. F7 in an `Agent` call counts the subagent transcripts'
  last move. Tests for all three. SKILL.md: F14 in the tables and Judge, the F6/F14 resume prompts "as its
  coordinator", the start through `create.py --from 30 --model opus --effort medium --exact`, the fix-agent prompt
  with the sentence and sized rows (test and fix opus high 1m, logs and uat sonnet medium 1m, Size by the rubric,
  `plan.py check`). cases.md: the two background-task cases name what the scan now does.
- **fix-loc**: `loop.py tick` takes `--coordinator-model` (alias `--model`, default `claude-sonnet-5-5`, D15),
  `--coordinator-effort` (default `medium`) and `--step-model` (alias, default `sonnet`); flag, else `state.json`'s
  `settings`, else default, stored back in `settings`; the start runs `create.py --from 30 --model --effort --exact`
  (a module path the tests replace by a fake). `servant-prompt.md` gets the sentence and the sizing (`{step_model}`
  medium 1m, Size by the rubric). SKILL.md: "loop session" for the loop, the new flags, the start; tick.py's docstring.
- **shoot / digest-todolist-picture**: `implement.py send` takes `--model` (default `opus`) and `--effort` (default
  `medium`), passes them to create.py; for `--pane` (a claude session) it reads the session's model and effort from
  its transcript's main chain (plan's session.py `scan`, no env fallback) and, when either differs or is unknown,
  restarts it through `hal2-cli-agents switch <pane> --model --effort --prompt <shot> --detach --json` instead of
  typing. The FALLBACK's item 7 says to run the plan as its coordinator plus the sentence; a template without the
  sentence gets it appended. Tests: the sentence, the flags to `worktree run`, switch vs typing. SKILL.md texts
  (shoot step 3 and Where; digest's send) follow.
